# Panduan Optimasi SEO & Structured Data

Template ini dirancang dengan standar SEO modern agar website bisnis Anda mudah diranking oleh mesin pencari Google.

---

## 1. Menyesuaikan Meta Tag di `index.html`
Buka file `index.html` dan sesuaikan tag berikut:
- `<title>`: Judul website bisnis Anda
- `<meta name="description">`: Ringkasan 1-2 kalimat mengenai profil usaha
- `<meta property="og:title">`: Judul share sosial media
- `<meta property="og:description">`: Deskripsi share sosial media

---

## 2. Mengubah File `public/robots.txt` dan `public/sitemap.xml`
- Ganti `https://example.com` di `public/robots.txt` dan `public/sitemap.xml` dengan domain resmi Anda.
- Sitemap membantu Google mengindeks seluruh halaman utama: `/about`, `/services`, `/products`, `/blog`, dan `/contact`.
