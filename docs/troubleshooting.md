# Panduan Troubleshooting & FAQ Teknis

---

## 1. Pesan Error Saat `npm install`
- **Penyebab:** Versi Node.js di komputer Anda terlalu usang.
- **Solusi:** Unduh dan pasang Node.js versi LTS terbaru dari [nodejs.org](https://nodejs.org).

## 2. Port 3000 Sedang Digunakan
- **Solusi:** Vite akan otomatis menawarkan port alternatif (misal port 3001) atau matikan proses yang sedang memakai port 3000.

## 3. Data Tidak Berubah Setelah Diedit di CMS
- **Solusi:** Pastikan Anda menekan tombol **"Simpan Perubahan"** di bagian atas Admin Portal.
- Jika browser Anda berada dalam mode Incognito/Private yang membatasi LocalStorage, beralihlah ke mode browser normal.

## 4. Ingin Mengembalikan ke Setelan Awal
- Klik tombol **"Reset Demo"** di Admin Portal untuk mengembalikan seluruh data ke default awal.
