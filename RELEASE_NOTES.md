# Release Notes — NASLA DIGITAL Business Website Template v1.0.0

## Ringkasan Rilis (v1.0.0 Stable Commercial Release)
Ini adalah rilis komersial perdana untuk produk digital **NASLA DIGITAL — Business Website Template** yang didistribusikan melalui Lynk.id.

---

## 🌟 Fitur Utama (Features)
- **Multi-Page Experience:** Halaman Home, About, Services, Products, Blog, Contact, dan 404 Not Found.
- **5 Industry Presets:** Penerapan cepat 1-klik untuk Digital Agency, Kontraktor/Konstruksi, Kuliner UMKM, Konsultan Legal, dan Distributor B2B.
- **Admin Demo CMS:** Panel pengelolaan konten mandiri di `/portal` berbasis LocalStorage dengan fitur Reset Demo Data.
- **WhatsApp Direct Checkout:** Form order dan keranjang belanja otomatis terformat rapi ke WhatsApp admin tanpa database eksternal.
- **Modern Responsive Design:** Dibangun dengan Tailwind CSS v4, Plus Jakarta Sans typography, dan dark mode glassmorphism accents.
- **SEO Ready:** Meta tags terstruktur, sitemap.xml, robots.txt, dan OpenGraph preview.

---

## 🔐 Catatan Keamanan (Security Notes)
- Admin Login yang disediakan menggunakan mode **Demo Authentication** (`admin` / `demo-admin`) yang disimpan di browser.
- Tidak ada kredensial sensitif atau API keys rahasia yang disimpan dalam frontend template ini.

---

npm install
